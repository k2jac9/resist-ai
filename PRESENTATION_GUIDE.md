## 🎥 Method 2: Export as Video (Detailed Steps)

### Step 1: Open the Presentation
```
1. Open ResistAI_Presentation.pptx in PowerPoint
2. Review all 21 slides
3. Make any edits you want
```

### Step 2: Add Narration (Optional but Recommended)

**Option A: Record Narration on Each Slide**
1. Go to **Slide Show** tab
2. Click **Record Slide Show** → **From Beginning**
3. A recording window opens
4. For each slide:
   - Speak your narration
   - Click arrow to advance
   - PowerPoint records timing automatically
5. When done, click "End Show"

**Suggested Narration Times:**
- Slides 1-4 (Problem): 1 minute total
- Slides 5-8 (Solution): 1 minute
- Slides 9-12 (Demo/Results): 1 minute
- Slides 13-19 (Details): 1.5 minutes
- Slides 20-21 (Close): 30 seconds

**Option B: Record Audio Separately**
1. Use Voice Recorder app
2. Record entire narration (5-7 min)
3. Insert → Audio → Audio on My PC
4. Select your audio file
5. Set to play automatically across all slides

### Step 3: Set Slide Timings

If you didn't record narration:
1. Go to **Transitions** tab
2. Set "After" timing for each slide:
   - Title slides: 3 seconds
   - Content slides: 5-8 seconds
   - Impact slides (big numbers): 4 seconds
3. Apply to all slides

### Step 4: Export as Video

**PowerPoint Export:**
1. File → Export → Create a Video
2. Choose quality:
   - **Full HD (1080p)** - Recommended
   - Ultra HD (4K) - If you have time/space
3. Choose timing:
   - "Use Recorded Timings and Narrations" (if you recorded)
   - "Don't Use Recorded Timings and Narrations" (set default: 5 seconds per slide)
4. Click "Create Video"
5. Choose location and filename
6. Wait for export (may take 5-10 minutes for 21 slides)

**Output:** MP4 video file ready for submission!

## ✏️ Customization Tips

### Want to Add Screenshots from Live Demo?

1. Take screenshots (Win + Shift + S)
2. In PowerPoint: Insert → Pictures
3. Add to relevant slides (after Slide 9)
4. Arrange and caption them

### Want to Change Colors?

1. Design tab → Variants → Colors
2. Or manually:
   - Select shape
   - Shape Fill → choose color
   - Current scheme: Green (primary), Red (urgency), Dark gray (text)

### Want to Add Your Logo?

1. Insert → Pictures
2. Add your logo
3. Position in corner
4. Copy to all slides (Ctrl+C, navigate, Ctrl+V)
