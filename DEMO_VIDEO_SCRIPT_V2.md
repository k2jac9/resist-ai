## 🎙️ Audio Tips

### Voice Recording
- **Microphone:** Use best available (headset mic is fine)
- **Environment:** Quiet room, minimal echo
- **Distance:** 6-12 inches from mic
- **Volume:** Speak at normal conversational volume
- **Tone:** Professional but enthusiastic—you're excited about this!

### Enunciation
- **Numbers:** "One point two seven million" (not "one-two-seven")
- **Acronyms:** "F-D-A" (spell it out), "A-M-R" (spell it out)
- **Model names:** "Evo-two-forty-B", "Boltz-two", "Qwen-three-two-three-five-B"

### Energy
- **Start strong:** Hook them in the first 10 seconds
- **Build excitement:** Pipeline running is the climax
- **Peak at results:** "Look at this!" energy
- **End confident:** Strong closing statement

## 📹 Recording Methods

### Method 1: Windows Game Bar (Easiest)
```
1. Win + G to open Game Bar
2. Click Record button (or Win + Alt + R)
3. Perform demo following script
4. Win + Alt + R to stop
5. Video saves to: C:\Users\[You]\Videos\Captures\
```

### Method 2: OBS Studio (Professional)
```
1. Download from obsproject.com
2. Add "Display Capture" source
3. Click "Start Recording"
4. Perform demo
5. Click "Stop Recording"
```

### Method 3: Automated (Playwright Script)
```
1. pip install playwright
2. playwright install chromium
3. python scripts/record_demo_video.py
4. Script automates browser, you add voiceover later
```
